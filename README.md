# ChatCircle

ChatCircle is a real-time group chat Android application.

## Project Status

Project setup and architecture in progress.

## Features

- Email and Google authentication
- Create or join chat rooms
- Real-time messaging
- Online/offline presence
- Image sharing
- Unread message indicators
- Push notifications
- User profiles

## Tech Stack

- Kotlin
- Android
- Jetpack Compose
- MVVM
- Firebase
- Hilt

## Architecture

The application follows a three-layer architecture:

- UI
- Domain
- Data
